# Security Policy

## Reporting a Vulnerability

This repository is the catalogue for the VoiceTel SDK family — its
content is documentation (`README.md`, `LICENSE`) only; there is no
executable code shipped from this repo.

For vulnerabilities in **any of the SDK repos**, the **CLI**, or the
**API collections**, please report them privately on the affected
repository:

| Surface | Report |
| ------- | ------ |
| 🐹 Go SDK | <https://github.com/voicetel/go-sdk/security/advisories/new> |
| 🐍 Python SDK | <https://github.com/voicetel/python-sdk/security/advisories/new> |
| 🟦 TypeScript / Node SDK | <https://github.com/voicetel/typescript-sdk/security/advisories/new> |
| ☕ Java SDK | <https://github.com/voicetel/java-sdk/security/advisories/new> |
| 🟪 C# / .NET SDK | <https://github.com/voicetel/csharp-sdk/security/advisories/new> |
| 🐘 PHP SDK | <https://github.com/voicetel/php-sdk/security/advisories/new> |
| 💎 Ruby SDK | <https://github.com/voicetel/ruby-sdk/security/advisories/new> |
| 🦅 Swift SDK | <https://github.com/voicetel/swift-sdk/security/advisories/new> |
| 🟧 Kotlin SDK | <https://github.com/voicetel/kotlin-sdk/security/advisories/new> |
| 🔴 Scala SDK | <https://github.com/voicetel/scala-sdk/security/advisories/new> |
| 🦀 Rust SDK | <https://github.com/voicetel/rust-sdk/security/advisories/new> |
| 🌙 Lua SDK | <https://github.com/voicetel/lua-sdk/security/advisories/new> |
| 🔧 CLI | <https://github.com/voicetel/cli/security/advisories/new> |
| 📦 API Collections | <https://github.com/voicetel/api-collections/security/advisories/new> |

For a cross-cutting issue that affects every SDK (spec drift,
shared model defect), file the private advisory against whichever
SDK first reproduces the issue and we will fan it out to the others.

For issues in this catalogue's own content (broken links, stale
version references) please open a regular public issue — those are
documentation defects, not security ones.
